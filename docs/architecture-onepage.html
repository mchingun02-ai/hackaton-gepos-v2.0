Тусгаарлалт — кодоор албадсан, prompt-оор биш

  1. Tenant зөвхөн session / түлхүүр / гарын үсэгтэй токеноос тодорхойлогдоно.
  2. AI хэрэгсэлд tenant параметр байхгүй — загвар өөр дэлгүүрийг «сонгож» чадахгүй.
  3. Query бүр :tenant-тай; өөр дэлгүүрийн id → «олдсонгүй» (404).
  4. Мессеж, баримт, зургийн бичвэр = өгөгдөл, заавар биш.
  5. Түнш ≠ мерчант: partner key яриа, мэдлэгийн сан, харилцагчийг уншихгүй.
  6. Автомат тест: хуурамч толгой/токен, prompt injection, зэрэгцээ ачаалал.
