# Gerege AI ажилтан

ПОС мерчантад зориулсан AI ажилтан. Харилцагчид Messenger, вэб чат болон дуудлагаар хандахад мэдлэгийн сан, ПОС-ын бодит өгөгдөл дээр тулгуурлаж хариулна. Ярианаас харилцагчийн датаг цуглуулж, хүсэлт, гомдлыг бүртгэнэ. Захирал энгийн үгээр тушаал өгөхөд ПОС, CRM, урамшуулал болон сувгууд дээр бодит үйлдэл хийнэ.

## Хаана юу байна

| Хаяг | Хэнд | Юу хийх |
|---|---|---|
| `/ai` | Захирал (РД + PIN-ээр нэвтэрнэ) | Тушаал (бичих, ярих), Харилцаа, Хүсэлт·гомдол, Харилцагчид, Мэдлэгийн сан, Багц·төлбөр, Тохиргоо |
| `/ai/chat?w=<widget токен>` | Харилцагч | Вэб чат (утсанд тохирсон). Холбоос, QR — Тохиргоо → Сувгууд (РД URL-д гарахгүй; «Холбоос шинэчлэх»-ээр хуучныг хүчингүй болгоно) |
| `/ai/call?w=<widget токен>` | Харилцагч | AI дуудлагын төв, монгол яриа |
| `/api/mcp` | Гаднын AI клиент | MCP сервер (Streamable HTTP, `Authorization: Bearer gai_…`) |
| `/`, `/portal`, `/merchant`, `/shop` | ПОС ба портал | AI-ийн өөрчлөлт эдгээр дэлгэцэд шууд (SSE-ээр) харагдана |

## Архитектур

```
Харилцагч ─ FB webhook / вэб чат / дуудлага ─┐
Захирал ─ /api/agent/command ─────────────────┼─► agent.ts (Qwen tool-calling давталт, ≤6 алхам)
Гаднын AI ─ /api/mcp (JSON-RPC) ──────────────┘        │
                                                         ▼
                                   tools.ts — 24 хэрэгсэл, нэг бүртгэл
                                   (бараа, үнэ, үлдэгдэл, тайлан, захиалга, урамшуулал,
                                    CRM, тасалбар, мессеж илгээх, мэдлэгийн сан, дүн шинжилгээ)
                                                         │
             ┌───────────────────────────────────────────┼────────────────────────┐
             ▼                                           ▼                        ▼
  sp/core.ts + sp/server.ts                 agent/crm.ts, kb.ts            billing.ts
  Store Plus төлөв (SQLite, rev, аудит)     харилцагч, яриа, тасалбар,     QPay v2, кредит,
  → /api/sp/events (SSE) → ПОС, портал       вектор мэдлэгийн сан           хэрэглээ
```

- **Өгөгдөл:** `data/gerege-ai.db` (SQLite). Store Plus-ын төлөв өмнө нь зөвхөн хөтчийн localStorage-д байсан. Одоо хөтөч (`sp/store.tsx`) өөрчлөлт бүрийг `/api/sp/state` руу илгээж, серверийн өөрчлөлтийг SSE-ээр хүлээн авна. Төлөв зөрвөл (409) серверийнх давуу эрхтэй.
- **AI (зөвхөн Qwen, Alibaba Cloud Model Studio):** `qwen-plus` агент ба tool calling-д, `qwen-flash` харилцагчийн картын мэдээлэл гаргахад, `text-embedding-v4` мэдлэгийн санд, `qwen3-omni-flash` яриаг сонсож текст болгоход, `qwen3-tts-flash` хариуг дуугаар уншихад ашиглагдана. Бүгдийг `.env.local`-д тохируулна.
- **Эрсдэлтэй үйлдэл** (захиалга цуцлах, буцаалт хийх, олон хүнд мессеж илгээх) захирлын «Батлах» товчийг хүлээнэ (`actions.status = pending`).
- **Урьдчилсан төлбөр:** кредит 0 бол AI хариулахгүй, яриаг ажилтанд шилжүүлнэ. QPay нэхэмжлэх үүсгээд `payment/check`-ээр баталгаажсаны дараа л кредит нэмэгдэнэ.
- **Facebook:** webhook-ийн шинэ текст мессежид AI зөвхөн Тохиргоо → «Facebook Messenger» асаалттай үед хариулна. Энэ тохиргоо анхдагчаар унтарсан байна.

## Одоогийн AI холболт (2026-11-17)

TokenHub (`AI_BASE_URL=https://api.tokenhub.mn/v1`) — Qwen gateway. Нээлттэй: `qwen3.6-plus` (агент), `qwen-flash` (карт), `text-embedding-v4`, `qwen3.5-omni-flash` (яриа сонсох), `qwen3.5-plus`, `qwen-max`.
- Дуугаар хариулах: TokenHub omni-ийн аудио гаралтыг дамжуулахгүй байгаа тул `AI_TTS_MODEL=none` — дуудлагад AI-ийн хариу текстээр харагдана. TokenHub аудио дэмжвэл энэ мөрийг устгахад omni-оор (voice `Tina`) уншина.
- Мэдлэгийн сан: гарчгаар хэсэглэж, вектор + BM25 хосолсон хайлт (монгол хэлэнд cosine бага гардаг).

## Нэвтрэлт, тусгаарлалт

Дэлгэрэнгүй: `docs/ARCHITECTURE.md` §3. Мерчант бүр зөвхөн өөрийн өгөгдлийг харна — кодоор албадсан (`src/lib/tenant/*`), тестээр нотолсон (`npm run test:isolation`).
- Самбар (`/ai`) — регистр + PIN (сервер шалгана) → HttpOnly cookie `gp_s`. ПОС, порталын серверийн синк ч энэ cookie-гоор (нэвтрээгүй бол «холбогдоогүй», локалаар ажиллана).
- Харилцагчийн чат/дуудлага — гарын үсэгтэй widget токен (`gwt_`) → зочны токен (`gvs_`, `POST /api/v1/widget/session`). Хуучин `?m=` холбоос 410.
- `.env.local`: `AUTH_SECRET` (32+ тэмдэгт, заавал), демо-д `AUTH_ALLOW_BOOTSTRAP=yes`.

## Ажиллуулах

```bash
cp .env.example .env.local   # DASHSCOPE_API_KEY-г бөглөнө
npm run dev                  # http://localhost:3100/ai
```

1. `/ai` → **Багц, төлбөр** → багц сонгож QPay (sandbox)-оор төлнө.
2. **Мэдлэгийн сан** → `docs/ai-employee/munkhod-juram.md`-г оруулна. Энэ нь демо мерчантын зохиомол журам.
3. **Тохиргоо** → вэб чат, дуудлагын QR-ыг утсаар уншуулж харилцагчийн үүргээр туршина.
4. **Тушаал** → жишээ тушаалуудыг өгнө. Өөрчлөлт `/portal` болон `/` (ПОС)-д шууд харагдана.

## MCP холболт

- **HTTP клиент:** URL `https://<host>/api/mcp`, header `Authorization: Bearer gai_…`. Түлхүүрийг Тохиргоо → MCP хэсгээс авна.
- **stdio клиент** (stdio дэмждэг MCP клиент):
  ```json
  { "mcpServers": { "gerege-ai": { "command": "node", "args": ["<repo>/scripts/mcp-stdio.mjs"], "env": { "GEREGE_AI_URL": "https://<host>/api/mcp", "GEREGE_AI_KEY": "gai_…" } } } }
  ```

## Хакатоны шаардлага

| Шаардлага | Хэрэгжилт |
|---|---|
| Realtime inference зөвхөн Model Studio-ийн Qwen | `src/lib/agent/qwen.ts` — DashScope-ийн compatible-mode болон native TTS endpoint. Өөр provider ашиглаагүй. |
| Төлбөр урьдчилсан, QPay | `billing.ts` — кредитгүй бол AI зогсоно. QPay sandbox нэхэмжлэх → шалгалт → кредит. |
| Өрсөлдөхүйц үнэ, 2–3 үйлчилгээтэй харьцуулалт | Багц, төлбөр хуудасны хүснэгт (эх сурвалж, огноотой) |
| Бодит харилцагчийн өгөгдөл ашиглахгүй | Демо мерчант «Мөнх-Од мини маркет» ба харилцагчид бүгд seed (зохиомол) |
